# Frameworks para Desenvolvimento de Software

Repositório criado para armazenar as atividades práticas desenvolvidas na disciplina **Frameworks para Desenvolvimento de Software** do curso de **Engenharia de Software**.

## 📚 Sobre o Projeto

Este repositório reúne os exercícios e projetos desenvolvidos durante as aulas práticas da disciplina, com foco na utilização de frameworks, bibliotecas e ferramentas amplamente utilizadas no desenvolvimento web.

## 🛠️ Tecnologias Utilizadas

* Java
* Java JDK
* Apache NetBeans
* Apache Tomcat
* Spring Web MVC
* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* JQuery
* ViaCEP API

## 📋 Atividades Desenvolvidas

### Atividade Prática 1

* Configuração do ambiente de desenvolvimento.
* Instalação e configuração do servidor Apache Tomcat.
* Integração do Tomcat com o NetBeans.
* Criação de uma aplicação Web utilizando Spring MVC.

### Atividade Prática 2

* Desenvolvimento de formulário de endereço.
* Utilização de HTML5, CSS3 e JavaScript.
* Consumo da API ViaCEP para preenchimento automático de endereço.

### Atividade Prática 3

* Criação de aplicação Web utilizando Spring Web MVC.
* Configuração do Bootstrap 5.
* Desenvolvimento de formulário de cadastro estilizado.

### Atividade Prática 4

* Desenvolvimento de formulário de cadastro com HTML5 e JavaScript.
* Utilização do Bootstrap 5 para estilização.
* Implementação de validações com JQuery.
* Integração com a API ViaCEP.

## 🎯 Objetivo

Aplicar na prática os conceitos relacionados ao uso de frameworks e bibliotecas para desenvolvimento de software, compreendendo sua importância na construção de aplicações modernas, organizadas e escaláveis.
